Cómo usarlo

Guía de uso paso a paso

Sigue este recorrido con el ejemplo de una pastelería para aprender el flujo completo del costeo estándar.

Configura tu empresa

Antes de costear, registra la información base del negocio.

  1. Ve a Datos generales → Empresa y completa nombre, NIT y datos tributarios.
  2. Crea el periodo contable con el que vas a trabajar.
  3. Registra las unidades de medida (g, kg, unidad, hora) y los centros de costo.
  4. Crea tus productos, por ejemplo: torta de vainilla, cupcake de vainilla y cupcake de chocolate.
💡 Solo el rol Administrador puede crear o eliminar empresas.

Registra materias primas

Define los insumos y sus valores estándar.

  1. Entra a Materias primas directas y pulsa Nuevo.
  2. Ingresa código, descripción, unidad de medida y proveedor.
  3. Define la cantidad estándar por producto y el precio estándar.
  4. Al registrar compras reales, Kosto calcula la variación de precio y cantidad.
💡 El sistema no permite códigos duplicados ni cantidades negativas.

Registra mano de obra

Configura los trabajadores y su costo por hora.

  1. Ve a Mano de obra directa y crea los cargos.
  2. Registra cada trabajador con su salario, prestaciones y cargas laborales.
  3. Kosto calcula la tarifa estándar por hora.
  4. Registra las horas estándar y reales para obtener las variaciones de tarifa y eficiencia.

Define los CIF

Asigna los costos indirectos a la producción.

  1. En CIF, registra los costos fijos y variables presupuestados.
  2. Elige la base de aplicación: horas MOD, horas máquina o unidades producidas.
  3. Kosto calcula la tasa predeterminada.
  4. Ingresa los CIF reales al cierre para obtener la variación.

Crea órdenes de producción

Registra lo que realmente se produjo.

  1. Ve a Producción → Nueva orden.
  2. Selecciona el producto, la cantidad y la fecha.
  3. Registra la materia prima utilizada y las horas trabajadas.
  4. El CIF se aplica automáticamente; marca la orden como terminada o en proceso.

Analiza variaciones y reportes

Compara lo estándar con lo real y toma decisiones.

  1. Abre el Dashboard y filtra por producto y periodo.
  2. Revisa en Análisis de variaciones qué fue favorable y qué no.
  3. Genera la hoja de costos y el estado de costos de producción.
  4. Exporta a Excel o PDF, o imprime directamente.
💡 Una variación desfavorable significa que el costo real fue mayor que el estándar.

Preguntas frecuentes

¿Tienes dudas?

¿Necesito internet para usar Kosto?

No. Kosto se instala en tu computador con su base de datos incluida y funciona sin conexión. Solo necesitas internet para descargarlo o para usar la demo en línea.

¿Qué requisitos tiene mi computador?

Windows 10 u 11 de 64 bits, 4 GB de RAM y unos 500 MB de espacio libre.

¿Tengo que instalar MySQL por aparte?

No. El instalador incluye todo lo necesario para que el sistema funcione.

¿Puedo exportar mis reportes?

Sí, todos los reportes se pueden exportar a Excel y PDF o imprimir directamente.

¿Qué diferencia hay entre los roles?

El Administrador gestiona todo el sistema y los usuarios; los Usuarios registran y consultan información; los Estudiantes tienen acceso de práctica con permisos limitados.

¿Cómo actualizo a una nueva versión?

Descarga el instalador más reciente desde esta página y ejecútalo; tus datos se conservan.
